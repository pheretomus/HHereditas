GENBANK READER:
- Never throw on malformed input: return best-effort records plus ParseWarnings with 1-based line numbers. Only text without any LOCUS line yields records: [] plus a warning.
- Accept \n, \r\n and \r line endings, a UTF-8 BOM, tabs, trailing spaces, slightly wrong indentation (fixtures invalid_locus_line_spacing.gb, wrong_sequence_indent.gb, pBAD30.gb uses CRLF), a missing '//' at end of file (no_end_marker.gb), a missing ORIGIN (no_origin_no_end.gb: sequence of N with the LOCUS length plus a warning), CONTIG-only records (warning), multi-record files (cor6_6.gb), empty sequences (blank_seq.gb).
- LOCUS: robust token-based parsing (old and new column layouts, long names that break the fixed columns, missing topology means linear, ds-DNA/ss-DNA/mRNA/RNA/DNA, 'aa' unit means protein, division, date). Warn if the declared length differs from the actual sequence length (trust the sequence).
- DEFINITION (multi-line, joined with single spaces) → description. ACCESSION, VERSION, KEYWORDS, SOURCE, ORGANISM (first line → meta.organism; taxonomy lineage lines kept so they round-trip), COMMENT (multi-line → meta.comments). Every other header block (REFERENCE/AUTHORS/TITLE/JOURNAL/PUBMED/REMARK, DBLINK, DBSOURCE, PROJECT, ...) is preserved verbatim and in order in meta.extraHeaderLines so GenBank → GenBank round trips are lossless (you decide how to place them on write so the output is valid GenBank that Biopython parses identically). meta.sourceFormat = 'genbank'.
- Sequence upper-cased; DNA records convert U to T; RNA records keep U; protein records (GenPept) get molecule 'protein'.
- FEATURES: key at column 6, location from column 22, location continuation lines (until parentheses balance and no trailing comma), qualifiers /key=value, /key="quoted ""escaped"" value" (escaped double quote = two quotes), unquoted values (codon_start=1, transl_table=11, anticodon=(pos:...)), value-less qualifiers (/pseudo → value null), multi-line quoted values (follow Biopython's joining rules: lines joined with one space, except /translation joined without spaces; check qualifier_escaping_read.gb and the oracle), empty values (empty_feature_qualifier.gb).
- Locations (INSDC feature table spec): 'n', 'a..b', '<a..b', 'a..>b', '<a..>b', 'a^b' (between-base site → zero-length segment at that gap), 'a.b' (treat as the range a..b), one-of(...) (first alternative plus warning), complement(), join(), order() (treat as join), nested complement(join(...)) and join(complement(a),complement(b)) (the latter lists parts in minus-strand 5'→3' order: reverse them into top-strand order per types.ts), remote references like AB123.1:10..20 (skip that part with a warning), mixed-strand joins (warning; majority strand). On CIRCULAR records contiguous parts crossing the origin (...L followed by 1...) merge into ONE wrapping segment (end > L), and a single range 'a..b' with a > b is a wrapping range (see bad_loc_wrap.gb, bad_origin_wrap*.gb, negative_location.gb). On LINEAR records a > b is invalid (warning; drop or best effort). Positions beyond the sequence → warning and clamp or drop, never crash.
- Feature name = featureLabel(type, qualifiers). Colours: consume ApE qualifiers /ApEinfo_fwdcolor and /ApEinfo_revcolor into feature.color / feature.reverseColor (normalize to '#rrggbb'; ApE also uses colour names such as cyan or pink: map common CSS colour names) and REMOVE them from qualifiers; also drop /ApEinfo_graphicformat. Feature ids via newId('f').
- Performance: fixtures/large/ecoli_U00096.3.gb (11.7 MB, ~4.6 Mb, thousands of features) parses in < 3 s and writes in < 3 s on this machine (test skipped when absent). Avoid quadratic string building.

GENBANK WRITER:
- Valid INSDC layout that Biopython parses identically: LOCUS line in the standard column layout (spaces in names → '_'; length; bp or aa; DNA/RNA/protein; circular/linear; division (keep the original if known, else a sensible default); date (keep the original, else options.date, else today in DD-MMM-YYYY)), DEFINITION wrapped at 80 columns, ACCESSION/VERSION/KEYWORDS/SOURCE/ORGANISM with sensible '.' defaults, preserved extra header blocks, COMMENT, FEATURES with locations wrapped at column 79 after commas and qualifiers wrapped at column 79 (inner '"' escaped as '""', avoid breaking inside words, known numeric qualifiers such as codon_start/transl_table unquoted, null value → '/key'), ORIGIN in the standard 60-bases-per-line, 10-base-block, right-aligned-number, lower-case format, terminated by '//'.
- If feature.name !== featureLabel(feature.type, feature.qualifiers), write or replace a /label qualifier so the user-visible name survives. Write color/reverseColor as ApEinfo_fwdcolor/ApEinfo_revcolor unless options.colorQualifiers === false.
- Wrapping segments on circular records → join(s..L,1..e); multi-segment features → join(...); strand -1 → complement(join(...)); partial ends with '<'/'>'; zero-length segments → 'a^b'.
- Sticky ends (record.ends) cannot be represented in GenBank: ignore them (the caller warns).

FASTA: multi-record; '>' header: name = first token, description = rest; ';' comment lines ignored; blank lines; digits/spaces stripped from sequence lines; detect protein vs DNA (letters only found in amino acids such as E F I L P Q → protein); '[topology=circular]' (NCBI modifier) in the header → circular; empty-sequence records allowed; warn on invalid characters. writeFasta: '>name description', 70 columns by default.
