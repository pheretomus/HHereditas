Build on the finished, reviewed modules (read their index.ts and sources first): src/enzymes, src/primers, src/ops, src/seq. Their API summaries are below.

API (results are objects such as { product?: SeqRecord; products?: SeqRecord[]; warnings: string[]; error?: string }: never throw on user-level problems such as incompatible ends; choose one consistent result shape and document it):
  pcr(template: SeqRecord, forward: Primer, reverse: Primer, options?: BindingOptions & { name?: string }): PcrResult
     // uses binding sites (forward primer strand 1, reverse primer strand -1). A productive pair → product = full forward primer (incl. 5' tail) + template between the annealed regions + reverseComplement(full reverse primer). Circular templates: products may span the origin. Linear templates: the reverse site must be downstream. Several possible products → all of them (sorted by size) plus a warning; none → error explaining why (no binding / wrong orientation). Product: linear, blunt; features = template features inside the amplicon (clipped → partial flags) shifted, plus 'primer_bind' features for both primers (full length incl. tails); name '<template> PCR' or options.name.
  digestRecord(rec: SeqRecord, enzymes: readonly RestrictionEnzyme[]): DigestedRecord[]   // SeqRecord & { parentRange, leftCut?, rightCut? }; each fragment has correct sticky ends (record.ends) and features clipped from the parent (extent includes overhang bases).
  endsCompatible(left: SeqRecord, right: SeqRecord): boolean   // right end of 'left' can ligate to the left end of 'right' (same kind, length and overhang text; blunt + blunt ok)
  ligate(parts: readonly SeqRecord[], options?: { circularize?: boolean }): LigationResult   // joins in order, shared sticky-end bases counted once; circularize requires compatible terminal ends; errors name the incompatible junction.
  restrictionClone(options: { vector: SeqRecord; insert: SeqRecord; vectorEnzymes: string[] /* 1 or 2 */; insertEnzymes?: string[] /* default: same */; vectorFragment?: 'largest' | number; insertFragment?: 'auto' | number; orientation?: 'both' | 'forward' | 'reverse' }): CloningResult
     // digest both, choose fragments (default vector = largest fragment; insert = the fragment whose ends are compatible with both vector ends — document tie-breaking), ligate in each viable orientation, return circular products with descriptive names and merged features; warn about hybrid sites that are not recut (e.g. BamHI/BglII), self-ligation risk for single-enzyme or blunt cloning, extra internal sites in the insert.
  gibsonAssembly(fragments: readonly SeqRecord[], options?: { minOverlap?: number /* default 15 */; maxOverlap?: number; circular?: boolean /* default true */ }): AssemblyResult
     // consecutive fragments must share terminal homology (last k bases of fragment i == first k bases of fragment i+1; take the longest k ≥ minOverlap); circular closes last→first. Product with merged features; junction report { overlapLength, overlapSeq, tm, gc }. Sticky ends are ignored (the exonuclease chews back 5' ends): document. Report missing overlaps (which junction), too-short overlaps, ambiguous/repeated overlaps, overlap Tm outside ~48–65 °C (warning).
  designGibsonPrimers(options: { vector: SeqRecord; insertion: Range /* region of the vector replaced; zero-length = insert at that gap */; inserts: readonly SeqRecord[] /* each amplified whole */; overlapLength?: number /* default 20 */; annealTargetTm?: number /* default 60 */; amplifyVector?: boolean /* default true: linearize the vector by PCR */ }): { primers: Primer[]; fragments: SeqRecord[]; product: SeqRecord; junctions: ...; warnings: string[] }
     // must be self-consistent: running pcr() with the designed primers and gibsonAssembly() on those products gives exactly the expected product (test this).
  goldenGate(parts: readonly SeqRecord[], options?: { enzyme?: string /* default 'BsaI' */; circular?: boolean }): AssemblyResult   // digest each part with the Type IIS enzyme, keep the fragment(s) lacking the recognition site, find the assembly ORDER from overhang compatibility (not array order), report duplicate or palindromic overhangs as errors.
  calculators.ts: dnaPmol(ng, lengthBp, doubleStranded = true), dnaNg(pmol, lengthBp, doubleStranded = true), insertAmountForRatio({ vectorNg, vectorLengthBp, insertLengthBp, molarRatio }), assemblyAmounts(...) for NEBuilder/Gibson planning. Document the formulas and the dsDNA mass-per-bp convention used, cite NEB/Thermo, and check against a few published example values.
